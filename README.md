# Cyber Awareness Selfie App

Privacy-first campaign app built with HTML, CSS, Bootstrap 5, JavaScript, Node.js, Express and SQLite.

## Run

```bash
npm install
npm start
```

Open `http://localhost:3000` and admin dashboard at `http://localhost:3000/admin`.

The SQLite database is created automatically at `data/campaign.db`. Selfies are processed entirely in the browser and are never uploaded to the server.

> Camera access works on localhost. A production deployment must use HTTPS.
